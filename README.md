# 人工智能文件處理系統 (OCR Document Processing System)

本專案為《人工智能文件處理》課程作品（專案編號：`11_CHUPUIYU`），結合全端響應式網頁、SQLite 關聯式資料庫、JWT 會員驗證與機器學習 OCR 文字辨識，支援上傳含文字的相片、自動擷取並儲存文字、關鍵字搜尋相關相片及刪除紀錄。

---

## 快速測試指南（給評分老師的測試步驟）

專案根目錄已內建 **`test-images/`** 資料夾，裡面放有預先準備好的含文字測試相片，老師啟動系統後可直接取用測試：

1. **啟動專案**：在終端機執行 `npm install` 安裝套件，設定 `.env` 後執行 `node server.js`。
2. **開啟測試網頁**：在瀏覽器開啟 `http://localhost:3000/`（支援桌面與手機螢幕尺寸）。
3. **註冊並登入帳號**：輸入自訂帳號（至少 3 字元）與密碼（至少 6 字元）註冊並登入。
4. **前往 `test-images/` 挑選測試圖片上傳**：
   * 在網頁點選「**選擇檔案**」。
   * 瀏覽至本專案資料夾下的 **`11_CHUPUIYU/test-images/`**，任選裡面的測試相片上傳並點擊「上傳並辨識」。
   * 系統會自動執行 OCR 文字辨識，並將相片與辨識出的文字顯示在下方列表。
5. **測試關鍵字搜尋與刪除功能**：
   * 在搜尋欄輸入相片中的任意關鍵字，即可篩選出相關相片與文字。
   * 點擊紀錄旁的刪除按鈕，可移除該筆測試紀錄與圖檔。
